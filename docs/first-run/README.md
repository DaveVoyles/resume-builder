# First-run guide for the agent

Read this folder at the start of every new person's setup. The person is a working professional. You run the tool. They decide what is true and when anything is sent.

| File | Use it for |
| --- | --- |
| [guide.html](guide.html) | The one page you open in their browser before anything else. A briefing: profile, resume, role list, interview brief. |
| [FAQ.md](FAQ.md) | The full path, from an empty folder to a resume, a tracker, and a study guide. |
| [what-to-say.md](what-to-say.md) | The exact sentences to say. Do not improvise jargon. |

Playbooks in `docs/playbooks/` are the detailed procedures for each later step. This folder is the spine that tells you when to use them.
